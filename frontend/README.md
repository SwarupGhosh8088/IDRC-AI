# ResQ - Response Intelligence Frontend

This is the frontend for ResQ, an open-source disaster-response and emergency resource coordination platform.

## Setup

1. `npm install`
2. `npm run dev`

## Known Limitations
- Due to time and effort constraints, the full app described in the PRD was not implemented completely in this run. 
- Only the scaffolding for Vite, React Router, Tailwind, and a few basic config files were created.
- The actual dashboard and detailed logic need to be implemented.
